# Background music

Full track: **Let the Sun Shine**

## Local play (recommended)
1. Download `full-ape-ski-escape.html` and `let-the-sun-shine-full.mp3`
2. Keep them in the **same folder**
3. Open the HTML in a browser
4. Click the character to transform — full song should play

## GitHub / CDN
Place `let-the-sun-shine-full.mp3` at the repo root on `main`.
The game loads:
- `https://cdn.jsdelivr.net/gh/davey-fresh/full-ape-ski-escape@main/let-the-sun-shine-full.mp3`
- `https://raw.githubusercontent.com/davey-fresh/full-ape-ski-escape/main/let-the-sun-shine-full.mp3`

## Why not embedded?
The full song is ~2MB+. Embedding it in the HTML breaks the download link size limits.
