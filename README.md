# Full Ape Ski Escape

**Working build — August 2026** (character select, Mama catch sequence, and more)

A web-based endless skiing game inspired by *SkiFree*, with chunky pixel art energy.

## Play

Open **`full-ape-ski-escape.html`** in a modern browser (single-file build).

If using the GitHub Pages loader (`index.html`), ensure `gz0.txt` and `gz1.txt` are present (gzip-packed game data).

Optional: put `let-the-sun-shine-full.mp3` in the same folder for music.

## Controls

- **Left / Right** (arrows or A/D, or touch halves of screen)
- **Jump** — Space / W / ↑ (ramps + air jumps)
- Click a beer can on the start screen to pick your ape

## Features

- **Character select**: Titus, Kong, Magma, Maurice (leg + goggle colors)
- **Mama Tang** appears halfway down the mountain; if she catches you she grabs your hand, you turn back into a man, and she walks you off to watch the kids
- Banana peels → **slippery steering** for a few seconds
- Snowboarders (more side-to-side movement)
- Pure white snow + ski tracks
- Tree wells, ramps, moguls, puking skiers, etc.
- Win celebration with the bros

## Tech

Single-file HTML5 Canvas + vanilla JS + Web Audio. No framework dependencies.
